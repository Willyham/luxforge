# Model Context Protocol schemas

The `luxforge-mcp` process tests validate every message the adapter writes against the
specification's own JSON Schema of the era it answers in. These files are unmodified copies from
the [Model Context Protocol specification repository](https://github.com/modelcontextprotocol/modelcontextprotocol)
at commit `dae694f61a31f7a3ec2af3aff709e11f70f61e48`. They are test inputs only; no binary
includes them.
