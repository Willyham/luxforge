# Linked ONNX Runtime prebuilt library

The local model runtime (`crates/luxforge-onnx`) runs models on ONNX Runtime 1.28.0, linked statically through the `ort` 2.0.0-rc.13 Rust binding. The library is not built from source: the `ort-sys` build script downloads pyke's prebuilt static archive for the target once, refuses it unless its SHA-256 matches the table in `ort-sys`'s own source (`build/download/dist.tsv`, pinned by the lockfile's checksum), and links `libonnxruntime.a` (or `onnxruntime.lib`) into the desktop and `luxforge-json`. Nothing is downloaded at run time. `cargo xtask check-repository` pins each archive's version, URL, length and SHA-256 (`xtask/src/onnxruntime.rs`); `cargo xtask onnxruntime-attestation` fetches each one and verifies its published build attestation.
