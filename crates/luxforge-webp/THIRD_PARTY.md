# Bundled WebP codec native source

WebP export encodes with libwebp as vendored and built by the `libwebp-sys` crate, through that crate's committed bindings and two declarations of libwebp's `sharpyuv` library, in one crate (`crates/luxforge-webp`). The C source comes from the pinned crate in the Cargo registry and is compiled at build time with the `cc` crate and the platform's C compiler and linked statically. Nothing is downloaded at run time, no system libwebp is loaded (the crate's `system-dylib` feature is off), and neither `bindgen` nor CMake is used.

Luxforge calls only the lossy encoder (`WebPEncode` with a YUV 4:2:0 picture), the RGBX picture import, the sharp RGB-to-YUV conversion (`SharpYuvConvert`) and the mux (`WebPMuxSetImage`, `WebPMuxSetChunk`, `WebPMuxAssemble`) | libwebp: BSD-3-Clause, with Google's additional patent grant; `notices/libwebp-1.6.0/COPYING` and `PATENTS` are the package's `vendor/COPYING` and `vendor/PATENTS`, copied by `cargo xtask inventory` to `native/libwebp-1.6.0/`. The crate's own bindings are MIT (its `Cargo.toml`); the package has no top-level licence file |

libwebp's errors are return codes, never an abort or an unwind: every failure of the encoder or the mux comes back as an error, and the progress hook and output writer catch a Rust panic at the C boundary and resume it once libwebp has returned. Manual license and native review remains deferred; this file records provenance, not a completed audit.
