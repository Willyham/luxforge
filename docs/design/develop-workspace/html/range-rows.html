The open rows

  1. One pick line. The first line under an open range row: Pick at rest, the accent bar with Done while the eyedropper is armed, in the same place, so arming moves nothing under it. The help button ends it in both states.

  3. Colour: swatches, then Refine. The swatch line ends with how many it holds or No colour yet; Refine is a slider, as the kind table declares it a setting rather than geometry.
  4. Mode as one chip, on every kind's row: the row's own mode, opening a menu of the three. The first row, always Add, shows none; the Add row ends with the same chip.
