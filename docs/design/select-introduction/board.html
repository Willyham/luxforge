Coming from Lightroom?

Import, then cull

  • Every frame you shoot goes into the catalog
  • Flags and stars are how you find the keepers
  • The catalog, previews and backups grow with every shutter press

Select, then develop

  • Choosing is its own fast step, one moment at a time
  • The catalog holds only what you develop: 20 picks from a 1,000-frame trip add 20
  • The rest stay on disk, organized again whenever you come back
Your files are never moved, copied or changed.

A modal sheet centred over Select, which stays visible behind the scrim so the regions the steps name are recognisable. Return or Start browsing closes it; Escape or ✕ closes it too. Add a folder… appears only while nothing is indexed and no card is mounted, and opens the same native dialog as the title bar's. Every colour comes from the theme's tokens, so a light theme keeps the hierarchy; the illustrations are drawn from those tokens, not shipped as images.
