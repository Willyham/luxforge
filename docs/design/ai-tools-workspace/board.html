The kind control gains a fourth segment, Object, beside Remove. Remove keeps exactly what is delivered: a press paints the area to fill, with no hover. Object has no brush in hand: the cursor is a crosshair, and the object under it is washed white inside a white outline over a dark under-stroke (Corrections' overlay treatment, which takes no hue from the photograph). Object… is the New mask and Add component menus' first Select entry; the later Select classes (Subject, Sky, People) join the same group. Choosing it enters a picking sub-state of Mask mode, as the range picker is: hover outlines, a click picks and commits one entry (Add object (model)) as a new mask, or as a component in the Add row's mode.
