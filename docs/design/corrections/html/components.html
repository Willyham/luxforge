Cursors and gestures

Addbrush, auto source
Add from set sourcesource follows the brush
⌥ heldclick sets the source
⌘-dragplace a spot, drag out its source
The brush is always in hand in Corrections. A press away from a pin always adds a new correction, over earlier ones included; the + says so. With a set source a crosshair rides at the offset. ⌥ swaps the brush for the source crosshair; ⌘-drag draws Lightroom's spot-and-source in one gesture.

Selected strokedrag pin moves the stroke
Only pins and the selected correction's handles are hit targets; the repaired area is not, so a stroke can start inside an earlier correction and stack over it. Overlapping pins pick the topmost. Each drag is one entry: Move Heal 5, Move Heal 5 source, Resize Heal 2.
