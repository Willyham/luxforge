# Feature status

| Capability | Status | Notes |
| --- | --- | --- |
| Repository checks, fixtures, smoke evidence, packaging | Implemented | macOS test launches run in background bundles without desktop activation; smoke and hardening use the editor; the tiered `verify` command runs a whole quick, rendered, timing or full check with one summary; [development](engineering/development.md) |
| JPEG open, automatic EXIF orientation, Fit, failed-replacement retention | Implemented (S0) | 8-bit sRGB and greyscale subset; broad ICC conversion and display calibration are not established |
| Windows/Linux automated builds and packages | Hosted baseline verified; refresh open | Native desktop checks deferred |
| License and dependency policy | Enforced | Manual license, native and asset review deferred; two expiring advisory exceptions ([dependencies](engineering/dependencies.md)) |
| Referenced assets in a SQLite catalog | Implemented (M1) | Stable IDs, fingerprints, explicit missing or changed-source errors |
| Copyable status and error messages | Implemented | Copy in the desktop status bar copies the full text; JSON failures expose code and message |
| Ordered non-destructive edit layers | Implemented (M1) | Stable layer IDs, immutable complete recipe snapshots |
| Test pixel-change tool | Implemented (M1) | Integer x/y in the content stage and 8-bit sRGB; placed before the geometry tail so crop changes never move it; exact lossless-buffer proof |
| Persistent history, undo/redo, append-only Restore | Implemented (M1) | Every committed action; all branches retained |
| History list, inspect, select and preview in UI and API | Implemented (M1) | Read-only preview and Return to current; `history.list` pages rows read from columns without stacks and `history.inspect` reads one whole entry; a desktop command reads back only what it changed and merges its row ([design](design/versions-and-lineage.md#history-rows)) |
| Save and reopen layers, history and navigation | Implemented (M1) | Atomic writes in the current catalog format; unsupported formats are refused |
| Fit, numeric zoom, 100% source detail and pan | Implemented (M1) | Physical-pixel 100% from the exact render; Fit and zoomed-out views are a display-bounded proxy render of the same recipe ([instant previews](design/instant-preview.md)); every zoom is drawn by the photo surface, which hands the GPU only its visible part and tiles a raster larger than the texture limit; verified on the M4 Mac from 50% to 1600% on 24 MP and 60 MP photographs by the `zoom` smoke scenario; per-client session state |
| Live JSON API and single-owner IPC | Implemented (M1) | Same service and history while the GUI is open |
| Invited shared editing with people or agents | Future possibility | [Design plan](design/shared-editing.md): host-led session and shared previews; remote access and collaborative undo are not implemented; no scheduled milestone |
| Rotate left/right, mirror horizontal, flip vertical | Implemented (M2) | Exact integer mappings composed into one orientation layer updated in place, always ahead of the crop; a transform made after a crop carries the crop in the same entry, so a crop draft shows the turned photograph; four rotations leave one neutral layer ([design](design/orientation-layer.md)) |
| Named versions and lineage view | Implemented | A version names a retained entry; lineage query and branch markers; catalog format 10 ([design](design/versions-and-lineage.md)) |
| Cached source and compiled one-pass rendering | Implemented | Point queries evaluate only the requested pixel or spatial tiles; a display-bounded proxy phase precedes a cancellable exact phase. Known cold RAW sources develop at the requested saved white balance, initial preparation overlaps desktop startup, DNG corrections and bounded native demosaic work use the shared pool, and spatial estimates reuse Dehaze atmosphere across strength edits. Qualification and scope are in [performance](specs/performance.md#startup-and-raw-throughput); [performance rules](engineering/performance-rules.md) |
| Content-space edits and `render.locate` | Implemented | Pixel-stage layers precede quarter-turns, reflections and crop; the canvas pick and the query map a rendered pixel to its content pixel ([design](design/content-space-edits.md)) |
| Declarative tool-module interface | Implemented (M3) | Descriptor-validated registry, generated `edit.<action>` methods and `module.list`; [modules](design/modules-and-api.md) |
| Pixel and transform tools as modules | Implemented (M3) | Registered effects and actions use the current payload shapes |
| Generic module controls and canvas pick in the desktop | Implemented (M3) | Controls rendered from descriptors; pointer pick fills coordinates without committing (pixel proof, `--developer`) |
| Lightroom-style crop and straighten module | Implemented (M4) | Normalized rotated-box payload, exact at 0°, linear-light bilinear resample otherwise, in-place layer updates; `edit.crop`, `edit.crop-fit`, `edit.crop-reset`; the panel's ratio and angle controls read the committed crop, and its ratio against the input stage `recipe.describe` reports for the crop layer behind any geometry, and open the draft with a change, and a reopened crop keeps the ratio its rectangle has; the open draft is the client's core `draft.*` draft, so `session.state` reports it and Apply commits it with `draft.commit`; a straightened draft of a photograph-sized stage is drawn as one tiled picture; a commit whose render fails shows the failure in place of the photograph, never the previous picture; a draft whose input stage fails or is superseded before it renders ends explicitly rather than waiting; verified on RAW by the `raw-panel` scenario; [crop contract](specs/single-image.md) |
| Draft conflicts with live agent commits | Implemented (M4) | Explicit Discard or Reapply; a stale draft keeps its composition and re-validates against the current stack |
| Resample stage boundary in the host pipeline | Implemented (M4) | Exact layers before and after compose as one raster pass each; at most two full frames exist at once, each within the [per-buffer limit](design/architecture.md#rendering-and-limits) for its path |
| Number parameters and crop-frame canvas in descriptors | Implemented (M4) | `number` parameter kind and the `crop-frame` canvas interaction, generated into desktop controls and the JSON API alongside `point-pick` |
| Develop workspace shell | Implemented | Title bar, collapsible state and tools panels (a module band shows its edited dot only while its current layer changes the picture, by the core's `neutral` answer), canvas with the floating mode strip (pointer, canvas-takeover modes and view overlays), draft bar and notices, status bar; dark theme; verified on the M4 Mac by the `workspace` and `unavailable` smoke scenarios; [design](design/develop-workspace.md) |
| Module panels | Implemented | Every tools-panel section drawn at one density and hierarchy: module bands, group rules with their captions, 30 pt slider rows, the mixer's groups as tabs, icon-button rows for transforms, the crop angle's rail, the white-balance rails and ellipsis truncation; a module whose controls are one group shows them with no sub-group header; a slider's double-click reset made while its commit is in flight waits for that commit; Inter bundled for semibold text; matched to the per-module references on the M4 Mac by the `basic-panel`, `presence`, `mixer`, `vignette`, `workspace`, `controls`, `crop-draft`, `raw-panel` and `gallery` smoke scenarios, with the remaining differences recorded in the [design](design/develop-workspace.md#what-is-not-matched) |
| Widget library and layered desktop | Implemented | `lightwell-ui` (Iced only, no core dependency); `app/`, `state/` and `view/` layers with the boundary enforced by `cargo xtask check-repository`; [architecture](design/develop-workspace.md#architecture) |
| Generated control vocabulary | Implemented | Soft-range sliders, number fields, steppers, toggles, segmented/chip/menu choices, colour fields/pickers, multi-channel curves, groups, resets and styled actions with vector icons, and canvas pick buttons. Slider drags use the declared step and precision; label or rail double-click resets the field. Continuous gestures whose field is a whole request draft as they move (at most one `draft.set` in flight, the newest value sent when it answers) and commit once; discrete controls commit once; no wheel editing. [UI components](design/ui-components.md) |
| Developer components gallery | Implemented | Title-bar Developer button in debug builds or with `--developer`; ten browsable pages of 64 shared reference states, page chooser, Back/Escape; the page is desktop view state, outside the core session, and browsing changes neither the photo nor the session |
| Controls developer proof and UI/API parity | Implemented | `lightwell.controls` is registered only in developer mode; one-field `edit.set-controls`, separate `edit.reset-controls`, module-owned sampled curves; exact identity pixels and source-buffer sharing. `text`, `pad` and `string` remain the second slice |
| History labels, recipe rows, module hints, resets and pickers | Implemented | `summary` templates rendered into stored entry labels (catalog format 10), `recipe.describe` with each layer's values, neutrality and input stage, `hint`, module and group `reset`, canvas `title` and `shortcut`, `picker` controls, `developer` flag, `layout` (`stacked` or `tabs`, validated at registration); all in `module.list` |
| Performance section, activity board and resource counters | Implemented | Pinned at the bottom of the state panel, open at launch: memory footprint, CPU and GPU with one-minute sparklines, and long-running work (original preparation, RAW development, preview renders, histogram jobs) from the host activity board; samples once a second only while expanded. `activity.list` and `resources.read` for any client. GPU time and allocations on macOS only; verified on the M4 Mac by the `performance` smoke scenario, which checks the memory figure against `ps` and `footprint` ([design](design/performance-panel.md)) |
| Per-client workspace state | Implemented | Panels, canvas mode and thirds through `workspace.set`, reported by `session.state` |
| Compare with the original, command palette, Copy as JSON request | Implemented | Hold `\` or Compare; Cmd+K runs every listed action and host command; a control's context menu copies its exact request |
| JPEG export with color and metadata verification | Editor follow-up | Quality 90, no overwrite, Keep metadata option |
| Manual Locate | Editor follow-up | [source recovery](specs/source-recovery.md) |
| MCP adapter | Editor follow-up | Same operation registry; the JSON API is not MCP |
| Complete editor packaging and portability verification | Editor follow-up | Native Windows/Linux remains deferred |
| External module loading | Required later | Selected use case and measured activation costs first |
| Multi-image library, filters, tagging, collections | Later | Owner workflow decisions first |
| RGB histogram, output clipping indicators/overlays, pixel readout | Implemented | Exact 256-bin counts of the rendered sRGB output after crop, the inspector a fixed-height plot and clipping triangles (the domain in the plot's tooltip, the endpoint counters in the triangles' tooltips, a missing analysis stated inside the plot, the pointer readout in the status bar) so the panel never changes height, blue/red/magenta overlays by the any-channel rule, `J`; `analysis.request/read/cancel`, `workspace.set` clip flags, `render.sample`; verified on the M4 Mac by the `histogram` smoke scenario ([design](design/basic-and-histogram.md)) |
| Basic: white balance with neutral picker, exposure, contrast, highlights, shadows, whites, blacks, vibrance, saturation | Implemented | One `lightwell.basic` layer before the geometry tail, evaluated in linear float with exact-threshold output quantization against independent f64 references ([tone](design/basic-tone.md), [white balance](design/basic-white-balance.md), [colour](design/basic-colour.md)); `edit.set-basic` field patches, `edit.reset-basic`, `query.neutral-sample`, the core draft lifecycle (`draft.*`) behind the slider gesture; verified on the M4 Mac by the `basic` and `basic-panel` smoke scenarios; relative JPEG corrections, not RAW recovery or Lightroom equivalence |
